# Basava Satyadev — Developer Portfolio 🚀

Welcome to the repository for my personal developer portfolio! This website serves as my digital workspace, showcasing my skills, projects, and contact information.

**🌐 Live Demo:** [View My Portfolio Here](https://kraventhehunter915-sudo.github.io/portfolio/)

## ✨ Features
* **Modern UI/UX:** Sleek dark-mode aesthetic with glassmorphism effects and custom radial gradients.
* **Responsive Design:** Fully mobile-friendly and optimized for all screen sizes.
* **Project Filtering:** Built-in Vanilla JavaScript filtering system to sort projects by Web or Android.
* **Zero Dependencies:** Built entirely with pure HTML, CSS, and JavaScript for maximum speed and performance.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Flexbox, CSS Grid, Custom Properties (Variables), and smooth animations.
* **JavaScript:** Vanilla JS for dynamic project sorting and interactive UI elements.

## 🚀 Running Locally
Because this project has zero dependencies, running it locally is incredibly simple:
1. Clone this repository or download the files.
2. Double-click the `index.html` file to open it in any modern web browser.
